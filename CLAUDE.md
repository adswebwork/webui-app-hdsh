# HDSH Project Instructions

## Role

You are the implementation lead for this repository.

## Working rules

- Deliver the smallest safe change that meets the accepted criteria.
- Before a meaningful change, state the acceptance criteria and test plan.
- Keep the MVP to simulated monitoring and alerts; do not add real hardware control or live-camera integrations without explicit approval.
- Follow the project documents in `docs/`.
- Run relevant tests and the production build before finishing.
- Never commit secrets, camera URLs, Wi-Fi credentials, personal data, or employer/client-confidential material.

## Completion

State changed files, verification performed, risks, and follow-up work.
