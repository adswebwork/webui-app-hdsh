# Healthy Dog Smart House

Healthy Dog Smart House (HDSH) is a monitoring-first smart-shelter concept. This repository contains a simulated dashboard prototype for testing how owners understand shelter conditions, device health, and alerts.

## MVP boundary

This is an assistive monitoring experience only. It does not control heaters, fans, food, water, relays, or live camera streams. It is not a substitute for owner supervision, safe shelter, or veterinary care.

## Local development

```sh
npm install
npm run dev
```

## Verification

```sh
npm test
npm run build
```
