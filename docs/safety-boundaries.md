# Safety Boundaries

HDSH is an assistive monitoring concept, not an autonomous animal-care system.

- Monitoring and owner alerts only in the MVP.
- No unattended mains power switching or direct control of portable heaters.
- No fuel-burning heat source.
- No automated feeding or watering.
- No real camera stream, credentials, household data, or personal data in the prototype.

Before any future actuator prototype, document failure modes; independent hardware safeguards; manual override; safe default state; device-health reporting; water, fire, electrical, and animal-contact risks; and a controlled no-animal test plan.
